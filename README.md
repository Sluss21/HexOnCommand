Adds a single command intended for use in datapacks alongside one attribute `hexoncommand:command_permission`

Example usage:

```
/attribute @p hexoncommand:command_permission base set 1
/hexcastinggui
```

Ported to 1.21.1 for personal use, perhaps others will want it for personal use as well.
Briefly tested on 1.21.1 Fabric and 1.21.1 Neoforge using Sinytra Connector.
